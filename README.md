# 🥗 PlateVision AI — Next-Gen Computer Vision Nutrition & Macro Tracker

> **PlateVision AI** is a state-of-the-art AI-powered web application that analyzes food photos using computer vision to instantly estimate calories, protein, carbohydrates, fats, and hydration targets. Designed with a sleek, dark glassmorphic UI using the **Lime Spark (`#B6FF2E`)** and **Graphite (`#23262F`)** brand aesthetic.

---

## 🚀 Key Features

* **📸 Computer Vision Food Scanner**: Upload or snap a dish photo to detect individual food items with glowing bounding boxes, precise calorie counts, and macro breakdowns.
* **🧠 AI Feasibility Assessment**: Multi-step onboarding wizard that evaluates user fitness goals (weight loss, muscle gain, maintenance) and provides real-time warnings if the weight target pace is too aggressive.
* **📊 Interactive Daily Dashboard**:
  * **SVG Calorie Ring Gauge**: Visual progress ring displaying consumed vs. target daily calories.
  * **Macronutrient Progress Bars**: Real-time tracking of Protein (g), Carbohydrates (g), and Fats (g).
  * **Hydration Tracker**: Interactive water bottle counter with quick `+250ml` logging.
  * **Meal History Timeline**: Logged meals grid featuring timestamped entries and macro chips.
* **⚡ AI Co-Pilot Advice**: Contextual nutritional feedback for every scanned plate.
* **🔐 Distinct Sign In & Onboarding**: Separate authentication and personalized evaluation flows.

## 📦 Getting Started

### Prerequisites

* Node.js 18.x or higher
* npm / yarn / pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone git@github.com:mfz-arch/PlateVision.git
   cd PlateVision
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
